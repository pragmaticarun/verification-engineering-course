# Quiz 1

Six questions. Open the note after you answer.

### 1

A pull request body says "all checks passed" and the CI panel is empty. What do you have?

??? success "Answer"

    A claim. The result would be a command that ran and an exit code stored against this tree. An empty panel is the absence of a result.

### 2

Why does the lab's starter ship `pr01`?

??? success "Answer"

    `pr01` has six ticks. The starter's rule is "ticks at least 6". The failing exit code is sitting in the same row and the starter never reads it.

### 3

### 4

Anthropic reported pull-request volume doubled and the revert share fell by more than 40 percent. Which mistake does that number not fix?

??? success "Answer"

### 5

Codex does not load `CLAUDE.md`. What does this course do about that in module 1?

??? success "Answer"

### 6

You can review twelve diffs in two hours, or sixty evidence records. When does the sixty become twelve again?

??? success "Answer"

    When the record is prose the agent wrote. You are then reading a diff that happens to be shaped like a report. The time goes back to the cost of reading an argument.
